# Cursor Spider - Animación Interactiva

Animación web interactiva desarrollada con **HTML, CSS y JavaScript** donde una criatura con estructura de araña sigue en tiempo real el movimiento del cursor en pantalla.

🚀 **[Ver Demo Online](https://fermin2020.github.io/Cursor-Spider/)**

---

## 🛠️ Tecnologías utilizadas

* **HTML5:** Estructura base de la página.
* **CSS3:** Estilos visuales y canvas.
* **JavaScript (Vanilla):** Lógica matemática y física de movimiento para las patas y el cuerpo.

---

## ⚡ Características

* Seguimiento de cursor fluido en tiempo real.
* Renderizado dinámico sobre HTML Canvas.
* Proyecto liviano construido sin librerías externas.
